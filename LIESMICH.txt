SECURE BOOT 2011 -> 2023  und  WINDOWS-11-CHECK            Kurzanleitung, Version 2.0
=====================================================================================
Alle .cmd per Doppelklick starten (fordern selbst Adminrechte an).
Stick vor dem Abziehen ueber "Hardware sicher entfernen" abmelden.
Ausfuehrlich: README.md

DIE STARTER
  1_Pruefen.cmd                          zeigt den Stand, aendert nichts
  2_Update_anstossen.cmd                 Windows spielt Zertifikate + Boot-Manager selbst ein
  3_Zertifikate_einspielen.cmd           2023-Zertifikate + Sperrliste von Hand, erst nach JA
  4_Experte_Schluessel_neu_aufbauen.cmd  Neuaufbau ueber Setup Mode (auch KEK 2023), 2 Laeufe
  5_Sicherung_zurueckspielen.cmd         fruehere Sicherung zurueckschreiben (Setup Mode)
  6_Windows11_Voraussetzungen_pruefen    CPU, RAM, Platte, Grafik, TPM, Secure Boot bewerten

NORMALER ABLAUF
  1. 1_Pruefen. Alles gruen = fertig.
  2. 2_Update_anstossen, neu starten, 1_Pruefen.
  3. Haengt es: 3_Zertifikate_einspielen (zeigt Plan, schreibt nach JA).
  4. Neu starten, 2_Update_anstossen (Boot-Manager), neu starten, 1_Pruefen.
  Fertig = db hat "Windows UEFI CA 2023" und der Boot-Manager ist damit signiert.
  KEK 2023 und volle dbx (~300 Hashes) sind Kuer. Ohne KEK 2023 startet der PC normal.
  KEK 2023 trotzdem gewuenscht: 4_Experte... (nicht auf HP Compaq Pro 6300).

SPERRLISTE OHNE KEK 2023
  Windows liefert die dbx nur noch mit KEK 2023 signiert. Fehlt der, nimmt 3_ die
  gleichwertigen KEK-2011-Dateien aus dem Ordner dbx_KEK2011 und bietet den Download
  von Microsoft (github.com/microsoft/secureboot_objects) an.

NOTFALL: PC startet nicht ("invalid signature")
  1. Firmware-Setup (Taste nennt 1_Pruefen; HP F10, Lenovo F1), Secure Boot AUS.
  2. Windows starten, 3_Zertifikate_einspielen.
  3. Secure Boot wieder AN.
  Oder: 5_Sicherung_zurueckspielen holt den Stand vor dem letzten Schreiben zurueck.
  "Setup Mode ohne PK" (HP Custom Keys): Secure Boot aus, Key Ownership "HP Keys",
  Windows starten, 3_, Secure Boot an.

NIE
  - Nach dem Boot-Manager-Tausch die Schluessel im BIOS loeschen oder auf Werkseinstellung
    setzen (ausser 1_Pruefen sagt, die Werkseinstellung kennt die Windows UEFI CA 2023).
  - DBXUpdate2024*.bin einspielen (sperrt PCA 2011). Die Skripte ueberspringen sie immer.

WINDOWS-11-CHECK (6_)
  gruen = offiziell ok, gelb = laeuft, aber nicht offiziell/knapp, rot = geht nicht
  CPU:   gruen ab Intel 8. Gen / Ryzen 2000, gelb aeltere Core i / Ryzen 1000 / FX,
         rot ohne SSE4.2 (Core 2, Phenom): 24H2 startet dort nicht
  RAM:   rot unter 4 GB, gelb 4 bis 8 GB, gruen mehr als 8 GB
  Platte: rot unter 64 GB, gelb HDD oder unter 128 GB, gruen SSD ab 128 GB
  Grafik: gruen WDDM 2.0 + DirectX 12, rot WDDM 1.x, gelb ohne Treiber
  TPM:   gruen 2.0, gelb 1.2 oder aus, rot keins (BIOS: PTT bzw. fTPM)
  Secure Boot: gruen an + 2023, gelb an + 2011 (weiter mit 1_ bis 3_), rot aus/Legacy

ABLAGE (lokal C:\ProgramData\SecureBootCheck\ und Kopie neben den Skripten)
  Logs\<PC>\  Backups\<PC>\  Rebuild\<PC>\  Uebersicht.csv  Win11_Uebersicht.csv
  <PC> = Hostname_Seriennummer
